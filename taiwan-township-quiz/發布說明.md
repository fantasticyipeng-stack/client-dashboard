# 台灣鄉鎮市區測驗 — 發布到網路

本專案是**單一 HTML 檔**，地圖資料與函式庫從網路載入，很適合用靜態網站方式發布。

---

## 方式一：GitHub Pages（免費，建議）

### 1. 把專案放到 GitHub

- 若還沒有 GitHub 帳號：到 [github.com](https://github.com) 註冊。
- 在 GitHub 建立新倉庫（例如 `taiwan-township-quiz`）。
- 在終端機進入專案資料夾，執行：

```bash
cd "taiwan-township-quiz"
git init
git add index.html 發布說明.md
git commit -m "Initial: 台灣鄉鎮市區測驗"
git branch -M main
git remote add origin https://github.com/你的帳號/taiwan-township-quiz.git
git push -u origin main
```

### 2. 開啟 GitHub Pages

- 在倉庫頁面點 **Settings** → 左側 **Pages**。
- **Source** 選 **Deploy from a branch**。
- **Branch** 選 `main`，資料夾選 **/ (root)**，儲存。
- 幾分鐘後，網站網址為：  
  **https://你的帳號.github.io/taiwan-township-quiz/**

> 若你把整個「try cursor」當成一個倉庫，而測驗在 `taiwan-township-quiz` 子資料夾裡，則網址會是：  
> **https://你的帳號.github.io/try-cursor/taiwan-township-quiz/**  
> 且 Pages 的 Source 要選到有 `index.html` 的那一層（或整個 repo，路徑就會如上）。

## 方式二：Netlify（免費，拖曳上傳）

1. 到 [netlify.com](https://www.netlify.com) 註冊／登入。
2. 在 Dashboard 點 **Add new site** → **Deploy manually**。
3. 把 **整個 `taiwan-township-quiz` 資料夾**（或至少包含 `index.html` 的資料夾）拖曳到網頁上的上傳區。
4. 部署完成後會得到一個網址，例如：  
   **https://隨機名稱.netlify.app**
5. 若你只上傳了 `taiwan-township-quiz` 資料夾內容，根目錄就是 `index.html`，直接開該網址即可玩。

---

## 方式三：Vercel（免費）

1. 到 [vercel.com](https://vercel.com) 用 GitHub 登入。
2. **Add New** → **Project**，選你放測驗的 GitHub 倉庫。
3. **Root Directory** 若測驗在子資料夾，設成 `taiwan-township-quiz`（或該資料夾名稱）。
4. 部署後會得到：  
   **https://專案名稱.vercel.app**

---

## 注意事項

- **網路**：測驗會從下列網址載入資源，發布後需能連線：
  - 地圖資料：`https://raw.githubusercontent.com/jason2506/Taiwan.TopoJSON/...`
  - 函式庫：`https://unpkg.com/`（d3、topojson-client）
- **HTTPS**：GitHub Pages、Netlify、Vercel 預設都是 HTTPS，可直接分享連結。
- **自訂網域**：上述平台都可綁自己的網域（在各自後台設定）。

---

## 建議流程（最簡單）

1. 在 GitHub 建一個新倉庫，只放 `taiwan-township-quiz` 裡的 `index.html`（可順便放本說明）。
2. 在該倉庫開啟 GitHub Pages，分支選 `main`、資料夾選 root。
3. 用 **https://你的帳號.github.io/倉庫名稱/** 分享給大家。

這樣就完成「發布到網路、給大眾玩」的設定。
